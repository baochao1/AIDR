# Agent 与插件的产品范围及验收

## 本轮用户流程

验证一台只装了 Agent 的终端可以接收、运行、停止和移除厂商能力，并把事件送达管理端。当前交互界面是 Windows Agent 演示控制台。

| 用户动作 | 本轮应看到的结果 | 验收证据 |
|---|---|---|
| 打开空白 Agent | 显示终端身份、Supervisor PID、空能力列表 | 界面与首条 check-in |
| 安装 AIDR 样例 | 出现组件版本、独立进程 PID 和本机连接方式 | 策略结果、实际能力列表 |
| 检查是否正常收数 | 进程和采集状态分别可见，展示已送达条数、已落库字节、待发条数 | 管理端记录和 event_id |
| 停止、重新启动 | 停止后不再收新事件，启动后恢复。已入队事件仍可发送 | 状态、组件 PID、计数变化 |
| 升级失败 | 显示期望版本、实际版本和失败原因，旧版恢复后显示实际旧版本 | 回滚记录 |
| 卸载 | 能力消失、安装目录移除，业务数据和历史事件保留 | 空列表、目录检查、同一 Agent PID |

样例发送合成事件。界面中已落库字节是管理端保存的事件 JSON 大小，生产网络流量和吞吐指标需要另定口径。

## 第三方业务边界

首轮要求厂商按[接入要求](aidr-vendor-handoff.md)交付独立适配器或 SDK，联通一条真实业务格式的测试事件。范围包括本地智能体、Skill、MCP 的发现，脱敏日志摘要、检测结果与风险。字段和隐私边界见[数据契约](aidr-data-contract.md)。正式检测效果、平台支持和权限需用厂商制品单独验收。

## 管理端后续设计

当前管理端提供最小配套能力：身份注册、签名制品仓库、按终端下发策略、状态查询和事件接收。

| 待设计事项 | 产品需要明确 |
|---|---|
| 终端与能力页面 | 设备列表、离线状态、期望/实际版本、进程/采集状态的呈现口径 |
| 发布运营 | 终端分组、灰度、审批、批量发布、重试和回滚权限 |
| 配置策略 | 规则版本、采集范围、日志字段、配置生效回执 |
| 数据与附件 | 资产 ID 归属、风险闭环、文件授权和保留期、查询与报表 |
| 生产验收 | 正式服务安装、系统权限、原生运行矩阵、离线窗口、性能和恢复覆盖 |

实施先后见[计划](plan.md)，可引用的实测证据见[验收记录](acceptance.md)。
