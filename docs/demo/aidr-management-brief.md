# 给老板的三分钟汇报

## 可以直接照读

> 我们做的是一个 Windows 终端的能力管理器。终端先装一次 Agent，后续需要哪家厂商的能力，就由平台下发对应组件。今天演示用的是我们准备的 AIDR 模拟组件，目的是验证第三方能力能装进去、能运行、能把数据送回来，以及能从终端撤掉。
>
> 第一张图是安装完成。AIDR 1.0.0 出现在终端的能力列表里，状态是运行中。它自己是一个独立程序，Agent 负责管理。
>
> 第二张图是数据验证。界面上的事件条数和数据量来自管理端实际已经收到并保存的记录。每条记录还有一个编号，可以从终端查到平台。
>
> 第三张图是卸载完成。AIDR 从能力列表消失，之前收到的记录还在。前后 Agent 的进程编号一致，说明给终端增加或撤掉能力时，Agent 一直在运行。
>
> 下一步请厂商交付一个符合约定的 Windows 组件，或提供 SDK 由我们做适配。双方先跑通一条真实业务格式的测试事件，再验收配置、稳定性和升级。今天验证的是接入和管理链路，实际检测效果需要用厂商组件单独验证。

## 现场操作与截图

1. 双击项目根目录的 Start-AIDR-Demo.cmd。等窗口显示「已连接」。
2. 点击「安装 AIDR 样例」。第一张图截到 aidr-mock、版本和「运行中」。
3. 等几秒，第二张图截到「已送达事件」「已落库事件数据」和最新事件编号。汇报中的「数据量」用已落库字节数描述。
4. 点击「停止」，需要演示可控性时再点「启动」。最后点击「卸载」，第三张图截到空能力列表、仍可见的历史事件和相同的 Supervisor PID。

界面的 aidr-mock 是我方提供的第三方角色模拟样例。正式接入时，这一行会换成实际厂商交付的组件及其版本。
